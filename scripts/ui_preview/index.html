About this preview: the Flutter mobile app itself can't be built inside this sandbox (the Dart runtime here cannot spawn any subprocess — flutter, flutter build web and dart analyze all fail for that reason). The backend API, however, is running for real: the demo flow above hit the live server — user registration, business creation, business switching (JWT with bid claim and real permissions), staff invite, 403 tenant isolation, 422 last-Owner protection and 400 validation all responded correctly. To run the actual app on this machine: cd apps/mobile && flutter pub get && flutter run (backend already running at :5182).
